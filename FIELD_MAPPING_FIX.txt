WHAT WAS FIXED
================================================================================

Before:
❌ Broad matching (e.g., any label with "court" → court_name)
❌ Overlapping conditions
❌ No priority order
❌ Data going to wrong fields

After:
✅ Exact label matching (e.g., "court name" → court_name)
✅ Priority order (specific before general)
✅ Duplicate prevention (only fill if empty)
✅ Data in correct fields

================================================================================
KEY IMPROVEMENTS
================================================================================

1. EXACT MATCHING
   Before: if 'court' in label
   After:  if label in ['court name', 'name of court', 'court']

2. PRIORITY ORDER
   - Advocate fields checked BEFORE party names
   - Specific labels checked BEFORE general ones
   - Prevents misclassification

3. DUPLICATE PREVENTION
   - Only fills field if currently empty
   - Prevents overwriting correct data
   - First match wins

4. EMPTY VALUE SKIP
   - Skips empty/null values
   - Prevents filling fields with blank data

HOW IT WORKS NOW
================================================================================

1. Read table row
2. Get label (first cell) and value (second cell)
3. Skip if value is empty
4. Check label against exact matches (priority order)
5. Only fill field if currently empty
6. Move to next row

Result: Each field gets the correct data!
